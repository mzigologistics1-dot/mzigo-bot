# Mzigo Logistics ZM 🚚
No Truck Returns Empty.

WhatsApp bot that matches empty trucks returning on Lusaka-Copperbelt corridor with cargo.

Live API: https://mzigo-bot.onrender.com
Test: /quote?from=Kitwe&to=Ndola&weight=2

How it works:
1. Trucker finishes delivery in Kitwe, sends "EMPTY Kitwe to Lusaka"
2. Trader needs to send goods, sends "LOAD Kitwe to Lusaka 2 tons"
3. Mzigo matches them.

Built on MTN Zambia 4G+ 🇿🇲
